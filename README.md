# Common Table Cafe
Final Project for Web Design I

## Files
- index.html - Home page
- menu.html - Full menu with prices
- story.html - Our story and milestones
- about.html - Hours, location, contact
- css/reset.css - reset file from class
- css/styles.css - main styles for all pages
- css/lightbox.css - gallery and lightbox (from class)
- js/lightbox.js - click a photo to make it bigger (from class)
- js/menu-filter.js - filter buttons on the menu page
- js/hours.js - shows "Open now" or "Closed now"
- images/ - all photos
